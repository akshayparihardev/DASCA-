> The official website for the **Data Science Association (DASCA)** at **RBU Nagpur**. Empowering students with data-driven insights, innovation, and collaboration.

---

## ✨ Features

- **🎨 Modern UI/UX**: Built with a "Wow" factor using Bento grids, glassmorphism, and premium gradients.
- **🌗 Dark Mode**: Fully supported system-wide dark mode with a neutral, premium dark palette (no blue tints).
- **📱 Fully Responsive**: Optimized for every device—mobile, tablet, laptop, and 4K desktops.
- **⚡ High Performance**: Powered by Next.js 16 (Turbopack) for blazing fast load times and optimized assets.
- **🎬 Interactive Animations**: Smooth, engaging animations using Framer Motion (float effects, scroll reveals, carousels).
- **👥 Dynamic Committee Page**: Interactive carousel and search functionality to find team members.
- **📅 Events Showcase**: Beautifully designed events section with decorative elements.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Shadcn UI](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) & Remix Icons

## 🚀 Getting Started

Follow these steps to set up the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/DascaRBU/DASCA-2026.git
cd DASCA-2026
```

### 2. Install dependencies
```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
